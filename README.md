# Highway WorkD V.3

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการและติดตามความก้าวหน้าโครงการก่อสร้าง พัฒนาขึ้นสำหรับสำนักทางหลวงที่ 18 (สทล.18) และแขวงทางหลวงในสังกัด เพื่อยกระดับการติดตามผลการดำเนินงาน การเบิกจ่ายงบประมาณ และการรายงานผลต่อประชาชนและผู้บริหารอย่างโปร่งใสและมีประสิทธิภาพ

## 🌟 ฟีเจอร์หลัก (Key Features)

* **Role-Based Access Control (RBAC):** แดชบอร์ดอัจฉริยะที่ปรับเปลี่ยนการแสดงผลตามสิทธิ์ของผู้ใช้งาน (ประชาชน, แอดมินแขวง, ผู้ดูแลระบบส่วนกลาง)
* **Interactive Drill-Down Charts:** ระบบกราฟภาพรวมระดับเขต ที่สามารถคลิก (Drill-down) เพื่อเจาะลึกดูเปอร์เซ็นต์ความก้าวหน้ารายโครงการของแต่ละแขวงได้ทันทีผ่าน Pop-up (สำหรับ Super Admin)
* **Data Isolation (RLS):** ระบบรักษาความปลอดภัยของข้อมูล แอดมินแต่ละแขวงจะมองเห็นและแก้ไขได้เฉพาะข้อมูลโครงการของแขวงตนเองเท่านั้น
* **Natural Sorting Algorithm:** ระบบจัดเรียงเลขที่สัญญาแบบอัจฉริยะ รองรับการเรียงตัวเลขภาษาไทย (เช่น สัญญาที่ 9 จะอยู่ก่อนหน้าสัญญาที่ 10 อย่างถูกต้อง)
* **Smart Data Import/Export:** รองรับการนำเข้า (Import) และส่งออก (Export) ฐานข้อมูลทั้งหมดในรูปแบบไฟล์ JSON พร้อมระบบแนบรหัสหน่วยงาน (`department_id`) ให้อัตโนมัติ
* **Real-time Summary:** กล่องสรุปยอดรวม (จำนวนโครงการ, งบประมาณรวม, ยอดเบิกจ่ายสะสม) ที่คำนวณแบบเรียลไทม์ตามกลุ่มผู้ใช้งาน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** HTML5, Tailwind CSS (ผ่าน CDN), Vanilla JavaScript
* **Data Visualization:** Chart.js
* **Backend & Database:** Supabase (PostgreSQL, Authentication, Row Level Security)
* **Hosting/Deployment:** GitHub Pages (หรือผู้ให้บริการ Static Web Hosting ทั่วไป)

## 👥 สิทธิ์การใช้งาน (User Roles)

ระบบแบ่งกลุ่มผู้ใช้งานออกเป็น 3 ระดับ ดังนี้:

1. **ประชาชนทั่วไปและผู้บริหาร (Public / No Login):**
* เข้าถึงหน้า `index.html` โดยไม่ต้องใช้รหัสผ่าน
* ดูภาพรวม 7 หน่วยงาน (1 สำนักฯ + 6 แขวงฯ)
* แสดงกราฟแท่งแบบ Stacked เปรียบเทียบ "โครงการที่แล้วเสร็จ" ซ้อนทับ "โครงการระหว่างดำเนินการ"


2. **แอดมินแขวง (District Admin):**
* เข้าสู่ระบบด้วยอีเมลของแขวง
* ดูหน้า Dashboard กราฟแท่งแสดง % ความก้าวหน้ารายโครงการ เฉพาะงานในแขวงของตนเอง
* เข้าถึงระบบหลังบ้าน (`dashboard.html`) เพื่อ เพิ่ม/ลบ/แก้ไข/อัปเดต สถานะโครงการได้เฉพาะของแขวงตนเอง


3. **ผู้ดูแลระบบส่วนกลาง (Super Admin):**
* ดูภาพรวม 7 หน่วยงานได้เหมือนประชาชน
* **ฟีเจอร์พิเศษ:** สามารถคลิกที่แท่งกราฟของหน่วยงานใดก็ได้ เพื่อเปิดหน้าต่าง Drill-down ดูกราฟรายโครงการของแขวงนั้นๆ
* เข้าถึงระบบหลังบ้านเพื่อจัดการข้อมูล นำเข้า หรือส่งออกข้อมูลโครงการของทุกหน่วยงานเพื่อสำรองข้อมูลได้



## 🏢 โครงสร้างรหัสหน่วยงาน (Department IDs)

ระบบอ้างอิงข้อมูลตามรหัสหน่วยงาน (`department_id`) ดังต่อไปนี้:

* `1` : สำนักทางหลวงที่ 18 สงขลา (DOH18)
* `2` : แขวงทางหลวงปัตตานี (PAT)
* `3` : แขวงทางหลวงสงขลาที่ 1 (SK1)
* `4` : แขวงทางหลวงสงขลาที่ 2 (นาหม่อม) (SK2)
* `5` : แขวงทางหลวงยะลา (YLA)
* `6` : แขวงทางหลวงสตูล (STL)
* `7` : แขวงทางหลวงนราธิวาส (NRA)

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)

**1. `doh_departments_v3**` (ตารางหน่วยงาน)

* `id` (int8, Primary Key)
* `name` (text)
* `code` (text)

**2. `doh_profiles_v3**` (ตารางผู้ใช้งาน)

* `id` (uuid, Primary Key, ผูกกับ Supabase Auth)
* `department_id` (int8, Foreign Key)
* `role` (text: 'admin', 'super_admin')
* `full_name` (text)

**3. `doh_projects_v3**` (ตารางโครงการ)

* `id` (uuid, Primary Key)
* `department_id` (int8, Foreign Key)
* `contract_number` (text)
* `project_name` (text)
* `progress_percent` (numeric)
* `status` (text: 'ระหว่างก่อสร้าง', 'แล้วเสร็จ', ฯลฯ)
* `total_budget` (numeric)
* `paid_amount` (numeric)

## 🚀 การติดตั้งและตั้งค่าเริ่มต้น (Setup & Installation)

1. **Supabase Setup:**
* สร้างโปรเจกต์ใน Supabase และสร้างตารางตาม Schema ด้านบน
* ตั้งค่า **Row Level Security (RLS)** ในตาราง `doh_projects_v3`:
* `SELECT`: เปิดสิทธิ์ `Enable read access for all users` (เพื่อให้ประชาชนดูกราฟหน้าแรกได้)
* `INSERT/UPDATE/DELETE`: กำหนดเงื่อนไขให้ Admin แก้ไขได้เฉพาะ `department_id` ของตนเอง และ Super Admin จัดการได้ทั้งหมด




2. **Environment Variables:**
* แก้ไขตัวแปร `SUPABASE_URL` และ `SUPABASE_ANON_KEY` ในไฟล์ `index.html` และ `dashboard.html` ให้ตรงกับโปรเจกต์ของคุณ


3. **Deployment:**
* อัปโหลดไฟล์ HTML ทั้งหมดขึ้น GitHub Repository
* เปิดใช้งาน GitHub Pages เพื่อให้ระบบออนไลน์พร้อมใช้งานผ่าน Browser
